1254×1254 투명 배경 PNG 생성물을 무손실 WebP로 변환했습니다. 로비는 얼굴 중심으로 표시하고 전투는 전신을 표시합니다. 서버 전투 기록에 맞춰 간단한 공격·피격 효과를 적용합니다. 3D 리깅·프레임 애니메이션은 포함하지 않습니다.

샨디 이미지는 제공되지 않아 자체 모델을 유지합니다. 이미지가 없거나 로딩에 실패해도 기존 플레이스홀더로 전투할 수 있습니다. 매핑과 출처 메타데이터는 `apps/web/src/art/heroes.ts`에 있습니다.

사용자는 허가된 이미지 기반 작업을 선택했으나 구체적인 원본 라이선스·필수 크레딧 조건은 제공하지 않았습니다. 이 문서는 원작 권리의 취득 또는 공개 배포 허가를 증명하지 않습니다. 실제 IP 사용 권한 확인은 기존 명세에 따른 별도 과제입니다.
