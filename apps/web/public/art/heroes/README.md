사용자는 허가된 이미지 기반 작업을 선택했으나 구체적인 원본 라이선스·필수 크레딧 조건은 제공하지 않았습니다. 이 문서는 원작 권리의 취득 또는 공개 배포 허가를 증명하지 않습니다. 실제 IP 사용 권한 확인은 기존 명세에 따른 별도 과제입니다.
