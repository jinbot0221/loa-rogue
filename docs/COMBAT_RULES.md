# Phase 2 전투 규칙 및 구현 범위

제품 명세를 토대로 만든 플레이 가능한 첫 전투 경로다. 원작 데이터/에셋을 추출하지 않으며 스킬 수치는 자체 플레이스홀더다. 일반층 이벤트 후보3개, 몬스터50종/보스별 독립 패턴, 장비/상점/균열12종은 아직 미구현이다.

## 도전과 권한

저장한 파티를 서버가 재검증하고 현재 스탯/코스트를 고정한다. 이후 로비 편성을 바꿔도 진행 도전에는 반영하지 않는다. 계정당 활성 도전은 DB partial unique index로1개만 허용한다. 행동, 난수, HP, 약 소비, 보상과 종료 결정은 서버가 계산한다. 클라이언트에 seed/RNG state를 전달하지 않는다.

도전 시작은 계정 revision, 도전 행동은 run revision을 사용한다. 모든 쓰기는 UUID actionId를 사용하며, 상태 저장·재화·기록·중복 응답 저장은 한 트랜잭션이다. 새로고침/서버 재시작은 도전을 종료하지 않는다. 다른 사용자의 도전 조회/조작은404다.

## 1대1과 턴

- 아군/적 각1명만 출전한다. 일반층은1명, 5의 배수 일반층은2명, 15의 배수 일반층은3명의 적이 순차 출전한다. 10층마다1명 보스다.
- 기본 공격/스킬/궁극기/약/자발 교체가 한 라운드다. 속도 비교 후 빠른 쪽부터 행동, 동속도는 저장된 시드로 결정한다. 먼저 쓰러진 배우의 예정 행동은 취소된다.
- 자발 교체는 일반 행동보다 먼저 실행되고 incoming 영웅이 적의 행동을 받는다. 자기 자신/사망 영웅/파티 밖 영웅으로 교체 불가.
- 선봉 사망 시 살아 있는 대기 영웅을 직접 선택한다. 강제 교체는 라운드·쿨다운·DoT·적 행동을 진행하지 않는다.
- 적을 쓰러뜨린 라운드에 다음 적이 즉시 공격하지 않는다. 모두 쓰러뜨리면 승리. 턴 종료 피해로 양쪽이 함께 전멸하면 플레이어 패배로 판정한다.

## 능력과 상태

- 피해: max(1,floor(power×ATK/(ATK+0.6×DEF)×modifier×0.95~1.05)). 기본 치명타5%, 배율1.5. 패시브는 `packages/shared/src/combat.ts` 및 엔진에 명시.
- 기본 공격/일반 스킬을 실제 사용하면 궁극기+25, 피격 시+10(최대100). 궁극기는100 필요/사용 후0. 막혀 실행되지 않은 행동은 게이지/스킬 쿨다운을 소비하지 않는다.
- 스킬별 쿨다운은 데이터에 명시. 모든 파티원의 쿨다운은 완료 라운드마다1 감소한다. CD2를 사용하면 이후2라운드를 다른 행동으로 보내고 다시 사용 가능. 층 전환 시 쿨다운 초기화.
- 무력화0이면 다음 행동1회 봉쇄 후 최대치 회복. 보스는 복구 후2라운드 무력화·기절 면역을 얻고 남아 있던 기절도 제거한다. 같은 라운드에 무력화와 기절이 걸린 일반 적은 각각 소비할 수 있다.
- 화상/출혈: 턴 종료에 고정 피해, 보호막 무시. 부여한 라운드부터 정해진 횟수만큼 피해 후 만료. 대기 영웅에게도 적용한다.
- 기절: 해당 유닛의 다음 행동을 건너뛰고 횟수를 차감한다. 이미 행동한 적에게 늦게 부여해도 다음 행동까지 유지된다.
- 감속: 명시 비율만큼 속도 감소, 부여 라운드에는 지속시간을 차감하지 않는다. 다음 라운드부터 우선순위에 반영.
- 같은 종류 상태이상은 중첩하지 않고 새 값/지속시간으로 갱신한다.
- 보호막: 현재/새 값 중 큰 값 사용, 중첩 합산 없음. 부여 라운드 포함3라운드 후 소멸. 일반 피해를 우선 흡수한다.
- 회복약: 도전 시작3개, 선봉 최대HP의40% 회복/1라운드. full HP 또는 수량0이면 거부. 기절로 사용하지 못하면 소비하지 않는다.
- HP/궁극기/약은 다음 층으로 유지한다. 층 전환 시 상태이상·보호막·무력화·쿨다운 초기화. 사망 영웅은 보상으로 부활하지 않는다.

## 층, 보상, 종료

1~100층을 순차 진행한다. 20층 단위5개 지역의 자체 적 템플릿을 사용하며 모든10층은 스케일링된 파수꾼 보스다. 보스는3번째 라운드마다 강공격을 예고하며 HP 절반 이하에서 강공격이 강화된다. 이 예고는 다음 적 행동으로 화면에 표시된다. 현재 고유 적 템플릿5종/공유 보스 패턴이며 명세의50종 완성으로 표시하지 않는다.

일반 승리 후 보상3개 중1개: 생존 파티HP25% 회복 / 궁극기35충전 / 골드25+5×층. 선택 후 다음 층으로 이동. 골드는 저장되지만 상점은 아직 연결되지 않았다. 100층 승리는 즉시 종료한다.

- 전멸: 최고 도달층×10 결정.
- 포기: 마지막 완료층×5 결정(1층 시작 직후 포기는0).
- 100층 클리어:1500, 계정 최초 클리어 추가1000.
- 지급과 기록은 DB에 정확히1회 반영. 종료 후 새로운 actionId로 재지급 요청도 거부. 결정 소비/영구 강화 구매는 Phase6 예정이다.

3D는 외부 에셋 없는 3등신 도형/저해상도 Toon 재질/보호막과 행동 움직임이다. 씬을 지연 로딩하며, 저사양2D 모드와 WebGL 실패 fallback에서도 모든 전투 API를 사용할 수 있다. 현재 원작 모델/화려한 스킬 이펙트/성우/음원은 포함하지 않는다.
