# 가로 화면 / 경로 맵 / SD 아트 준비

2026-11-14 · Node22.23.5 · Linux x64 / Chromium 소프트웨어 WebGL

## 실제 변경

- 전투의 상태/장면/명령/파티를 고정 레이아웃으로 분리.640×360,844×390에서 기본 공격/스킬2/궁극기/회복약5버튼,6영웅 교체 버튼이 뷰포트 안에 들어가고 각 터치 영역44px 이상. 페이지 자체 세로/가로 넘침 없음.
- 로비의6영웅 선택/파티 저장/도전 시작도640×360에 들어감. 편성 순서 목록/상세 도감은 내부 스크롤. 세로에서는 일반 스크롤과 가로 안내 유지.
- 가방,기록,상세 정보,도감,조합법은 native dialog로 열며 내부 목록만 스크롤. ESC/닫기,포커스 처리. 포기는 상단 메뉴에서 확인 후 실행.
- 독자적인 분기 경로 지도:100층,일반층3레인,10층 보스1개. 다음 층 인접 레인만 연결되어 선택 가능한 방은2~3개.10층 구역을5층씩 표시하며 현재 선택과 방문 경로/연결선을 보여줌. 방을 고르고 설명을 확인한 뒤 이동 확정.
- 맵 난수는 전투/장비 난수와 분리하며 JSON에 저장. public 응답은 현재10층 구역만 포함. 클라이언트가 임의 후보를 넣어도 미래/연결되지 않은 방은 서버 거부.
- 기존 맵 없는 활성 도전은 현재 후보/선택/전투를 보존하고 현재 위치를 복원. 다음 층부터 저장된 지도 경로를 이용. 새 DB 삭제/migration은 필요 없음(JSON에 optional map 확장).

## SD 이미지 상태

사용자는 허가받은 로아 원본 기반 SD 변환을 선택했다. 현재 원본 이미지와 허용 범위가 아직 첨부되지 않아 이미지 생성/편집은 실행하지 않았고 SD 결과 파일도 없다.

`apps/web/src/art/heroes.ts`의 영웅별 매핑, `HeroArtwork`와 로비/전투 연결은 준비했다. 매핑이 비어 있으면 기존 자체 모델/상징을 사용한다. 이미지 로딩 실패 시에도 플레이스홀더로 복구한다. 투명 WebP/PNG 아트를 추가하면2D 전투 표시/3D 장면의 영웅 이미지와 로비 카드에 적용된다.

필요 자료: 웨이/니나브/실리안/샨디/아제나·이난나/바훈투르 원본 이미지(우선1명부터도 가능),제공된 수정/게임 삽입/외부 공개/표기 조건. 원본을 받으면 이미지 편집 도구로 SD 변환하고 실제 결과물을 연결해 검증한다. 원본을 임의로 다운로드하거나 권한/크레딧을 만들어 넣지 않았다.
