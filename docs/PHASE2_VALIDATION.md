## 남은 제한

순차1~100층 전투 경로이며 일반층 이벤트3후보/장비/상점/균열12종은 아직 없음. 현재 적 템플릿5종과 공유 보스 패턴이며 명세의 일반30/정예10/보스10 고유 데이터는 후속 작업. 결정 지급/기록은 구현했지만 영구 강화 구매는 아직 없음.

3D 도형과 저사양2D fallback은 동작한다. 실제 MacBook GPU/모바일 실기기 성능 및 외부 HTTPS는 이번 클라우드 테스트로 검증하지 않았다.3D 씬은 지연로딩되지만 Three/R3F 청크약886KB(압축약239KB)로 Vite 경고가 남는다. Node22 SQLite 실험 경고 및 Zod Rollup 주석 경고도 출력되며 빌드/테스트는 성공했다.

Mac LaunchAgent는 파일 생성/내용/형식만 검증했다. 사용자 Mac 서비스 설치/launchctl/Cloudflare 자격증명/도메인 등록은 수행하지 않았다. 클라우드 환경 버전은 게시하지 않았다.
