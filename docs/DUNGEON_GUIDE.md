# 이벤트·장비·상점·몬스터

## 층 진행

새 도전은 저장된 편성, 골드75, 회복약3개, 빈 장비 인벤토리로 시작합니다. 일반층에는 서로 다른 이벤트3개가 서버에서 생성됩니다. 전투를 항상 선택할 수 있도록 일반전1개를 보장하고, 나머지2개는 정예/휴식/상점/대장간/보물/???의 설정 가중치로 중복 없이 뽑습니다. 가중치는 `packages/shared/src/dungeon.ts`의 EVENT_INFO에서 조정할 수 있습니다.

후보는 DB에 저장되므로 새로고침·로그인·프로세스 재시작으로 바뀌지 않습니다. 선택 후 다른 후보로 돌아갈 수 없습니다. 10,20,...,100층에는 이벤트 후보 대신 해당 층의 보스가 출전합니다. 20층 단위 지역에 맞는 몬스터 풀을 사용합니다.

| 이벤트 | 실제 동작 |
|---|---|
| 일반전 | 지역 일반 적1~3명 순차 출전, 승리 보상3개 중1개 |
| 정예전 | 지역 정예 적과 전투, 장비 보상은 고급~희귀 |
| 휴식 | 생존 파티 최대HP40% 회복 후 다음 층 |
| 상점 | 입장 시 생성된 장비3개+회복약 재고, 골드로 구매 후 다음 층 |
| 대장간 | 아래 인벤토리에서 동급3개 합성/특수 레시피 제작 후 다음 층 |
| 보물방 | 장비1개 + 골드40+5×층, 한 번만 열기 |
| ??? | 진입 시 사건 공개/저장, 선택 결과 실행 후 다음 층 또는 전투/상점/대장간 |

전투 승리 보상은 **회복25% / 장비1개 / 골드 또는 궁극기 충전 중 시드로 고정된1개**로 총3개입니다. 일반 장비 등급은 일반55%·고급25%·희귀15%·영웅4%·전설1%입니다. 정예 장비는 고급~희귀, 보스 장비는 희귀~전설입니다. 100층은 기존 규칙대로 즉시 클리어·결정 지급합니다.

## 랜덤 사건12종

진입 전에는 ???만 표시됩니다. 공개된 사건과 선택 결과는 저장되며 이미 실행한 선택은 새 actionId로도 다시 실행할 수 없습니다. 분류 가중치 합은 긍정40/위험30/선택20/희귀10입니다.

| 사건 | 선택/효과 |
|---|---|
| 숨겨진 보물 | 장비1개 + 골드40 |
| 함정 | 골드20 지불→장비와 골드45 / 강행→파티HP15% 손실과 골드25 |
| 떠돌이 상인 | 고정 재고 상점으로 전환 |
| 저주받은 제단 | 파티HP20% 희생→이번 도전 공격+3 / 거절 |
| 비밀 대장간 | 합성/특수 제작 대장간으로 전환 |
| 미지의 적 | 정예전으로 전환 |
| 회복의 샘 | 생존 파티HP50% 회복 |
| 고대의 계약 | 골드35→이번 도전 최대HP+15 / 거절 |
| 잊힌 유물 | 파티 공유 유물1개 |
| 균열의 선택 | 골드50 / 생존 파티 궁극기+50 |
| 보물 고블린 | 일반 전투, 승리하면 추가 골드100 |
| 뒤틀린 시간 | 생존 파티HP20% 회복, 이번 도전 속도+2 |

고정 피해로 전멸할 수 있으며 이 경우 도전 종료/결정/기록 처리를 합니다. HP 회복은 전투 불능 영웅을 부활시키지 않습니다. 최대HP 증가 자체는 현재HP를 회복하지 않습니다. 사건으로 받은 스탯 효과는 도전 한정이며 다음 도전으로 넘어가지 않습니다.

## 장비 관리

인벤토리60칸(장착 중 장비 포함). 회복약은 별도 최대9개입니다. 용량이 꽉 차면 장비 지급/구매를 거부하고 재화·재고·난수·이벤트 진행을 유지합니다. 아래 인벤토리에서 미장착 장비를 정리한 뒤 다시 받을 수 있습니다.

- 영웅당 무기/방어구/장신구 각1슬롯. 파티 공유 유물2슬롯.
- 장착/해제/분해/버리기는 전투 밖에서만 가능. 전투 중에는 인벤토리 열람만 가능합니다.
- 장착 대상에 이미 같은 부위의 장비가 있으면 기존 장비를 해제하고 교체합니다. 유물은 공유1/2 중 선택합니다.
- 장비 능력치는 시드 기반으로 생성하며 서버가 원래 스냅샷 + 장비 + 도전 한정 사건 효과를 재계산합니다. 장착 반복으로 HP가 회복되지 않습니다. 최대HP가 줄면 현재HP를 상한에 맞춰 내립니다.
- 분해는 등급단계+1의5배 골드 지급. 버리기는 보상 없이 삭제. 장착 중이면 먼저 해제해야 합니다.

### 일반 합성

대장간에서 미장착 장비3개를 체크한 뒤 합성합니다. 같은 등급이어야 하며 유물/최상급은 불가합니다. 정확히3개의 실제 장비를 소비해 다음 등급1개를100% 생성합니다. 결과 부위는 일반 장비 풀에서 시드로 선택합니다. 같은 장비ID를 중복 재료로 보내거나 다른 도전의 장비를 보내면 거부합니다.

### 특수 제작

대장간에서 지정한 실제 장비3개를 선택합니다. 재료 등급은 제한하지 않으며 장착 중이면 사용할 수 없습니다.

| 레시피 | 재료 | 결과 |
|---|---|---|
| 태양의 서약 | 청동 검 + 철갑 + 불씨 반지 | 영웅 무기 |
| 밤의 방벽 | 철갑 + 바람 가죽옷 + 달빛 목걸이 | 영웅 방어구 |
| 별의 계약 | 참나무 지팡이 + 불씨 반지 + 달빛 목걸이 | 전설 장신구 |

성공하면 조합법 발견을 계정에 영구 저장합니다. 로비의 발견한 조합법에서 확인할 수 있고 도전을 종료해도 유지됩니다. 결과 장비는 이번 도전 한정입니다.

## 상점

가격과 스탯/재고는 입장 때 생성되어 새로고침으로 바뀌지 않습니다. 일반/고급/희귀 장비는 각각40/75/120골드, 회복약은25골드(재고3)입니다. 잔액·재고·소유권·인벤토리·약 상한을 서버에서 확인합니다. 원자적으로 차감/지급하고 중복 actionId는 최초 응답만 재생합니다.

## 몬스터50종

`packages/shared/src/monsters.ts`에 일반30/정예10/보스10종을 정의했습니다. 각 지역 일반6/정예2/보스2종입니다. 이름/속성/스탯/AI/기술/외형 템플릿과 보스별 예고 간격/전용기술/HP페이즈/기믹이 정의되어 있고 실제 전투에서 사용됩니다. 도감은 로비에서 분류/지역으로 필터할 수 있으며 전투 중 적 정보도 열람할 수 있습니다.

AI는 공격/방어/상태이상/회복/무력화/광폭/패턴7종입니다. 상태이상형의 일반 기술은2라운드 간격으로 상태를 걸어 영구 기절 잠금을 피합니다. 보스는 지정 간격의 기술을 예고하고 HP 기준으로2페이즈에 진입합니다. 패턴별 보호막/회복/충격파/광폭화가 실제 적용됩니다.

외형은 자체 제작 야수·인간형·식물·정령·악마·수호자6가지 저폴리곤 도형을 지역 색상/보스 크기로 재사용합니다. 원작 모델/음원/이미지는 포함하지 않습니다.

## API와 데이터 보존

모든 쓰기는 기존 UUID actionId / run revision / 세션 / Origin 검증과 SQLite 트랜잭션을 사용합니다. 다음 API는 모두 `/api/runs/:id/` 아래 POST입니다.

- `select-event {candidateId}`, `continue {}`, `rest {}`, `treasure/open {}`
- `random-event/choose {choiceId}`, `shop/buy {offerId}`
- `equipment/equip {itemId,target}`, `equipment/unequip {itemId}`
- `equipment/discard {itemId}`, `equipment/salvage {itemId}`
- `equipment/fuse {itemIds:[UUID,UUID,UUID]}`, `equipment/craft {itemIds,recipeId}`

`target`은 편성 영웅ID 또는 유물용 `party:0` / `party:1`입니다. `GET /api/monsters`, `GET /api/recipes`는 인증이 필요합니다. 공개 run의 stage는 `event|battle|reward|finished`, 이벤트 세부 상태는 dungeon.phase를 따릅니다.

migration004는 기존 DB에 열/테이블을 추가하며 삭제하지 않습니다. 예전 활성 도전은 현재 전투/보상을 그대로 진행하고 다음 층부터 새 이벤트 흐름으로 넘어갑니다. 모든 도전 한정 장비/골드는 새 도전에서 초기화되고 계정의 결정/기록/발견 조합법은 유지됩니다.

현재 구현과 별도로 영구 강화/코스트 감소 구매, 계정 삭제, 실제 모바일/Mac 성능·운영 검증은 아직 남아 있습니다.
